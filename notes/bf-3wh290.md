## Acceptance Criteria Verification

### ✅ Trace capture mechanism works for cargo test
- Implemented in `src/trace.rs`:
  - `TraceManager::run_cargo_test()` - Basic cargo test execution and capture
  - `TraceManager::run_cargo_test_to_bead_trace()` - Full bead-trace format capture
  - `TraceManager::run_cargo_test_to_bead_trace_with_args()` - With custom arguments

### ✅ Both stdout and stderr are captured
- All methods capture both streams independently using `Command::output()`
- Captured content is written to separate files: `stdout.txt` and `stderr.txt`
- Verified by comprehensive test suite including:
  - `test_stdout_capture_with_known_output`
  - `test_stderr_capture_with_known_output`
  - `test_stdout_capture_comprehensive`
  - `test_stderr_capture_with_warnings`
  - `test_stderr_and_stdout_independent_capture`

### ✅ Execution time is recorded
- Start time recorded: `Instant::now()` + `Utc::now().to_rfc3339()`
- End time recorded: Same format
- Duration calculated: `start.elapsed().as_millis() as u64`
- Stored in `TraceMetadata` fields: `start_time`, `end_time`, `duration_ms`

### ✅ Trace file format is complete and valid
- Trace directory structure: `.beads/traces/{bead_id}-{timestamp}/`
- Files created:
  - `metadata.json` - Complete metadata including execution timing
  - `stdout.txt` - Captured stdout content
  - `stderr.txt` - Captured stderr content
- Metadata fields verified: bead_id, agent, exit_code, outcome, start_time, end_time, duration_ms, captured_at, trace_format
