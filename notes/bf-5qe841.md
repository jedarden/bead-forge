## How It Works

1. **Start Time Recording** (lines 729-730):
   ```rust
   let start = Instant::now();
   let start_time = Utc::now().to_rfc3339();
   ```

2. **Cargo Test Execution** (lines 733-742):
   - Runs cargo test with output capture
   - Even if tests fail or timeout, execution continues to timing code

3. **End Time & Duration** (lines 745-746):
   ```rust
   let end_time = Utc::now().to_rfc3339();
   let duration_ms = start.elapsed().as_millis() as u64;
   ```

4. **Metadata Update** (lines 756-758):
   ```rust
   exec_metadata.start_time = Some(start_time.clone());
   exec_metadata.end_time = Some(end_time.clone());
   exec_metadata.duration_ms = Some(duration_ms);
   ```

5. **Trace File Writing** (line 770):
   - Writes metadata.json with timing information
   - Uses unique timestamped trace directories

## Key Design Decision

Timing is captured **outside** the cargo test execution block to ensure accuracy even when:
- Tests fail (non-zero exit code)
- Tests timeout (cargo kills them)
- Cargo crashes

The `Instant::now()` before cargo execution and `Utc::now().to_rfc3339()` after completion guarantee accurate timing regardless of test outcome.
