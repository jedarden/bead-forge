## Trace Format Compliance

### Standard Agent Trace Format
All valid agent traces follow the standard format:
```json
{
  "bead_id": "bf-*",
  "agent": "claude-code-glm-*",
  "provider": "zai|anthropic",
  "model": "glm-*",
  "exit_code": integer,
  "outcome": "success|failure|timeout",
  "duration_ms": integer,
  "input_tokens": null,
  "output_tokens": null,
  "cost_usd": null,
  "captured_at": "ISO8601 timestamp",
  "trace_format": "claude_json",
  "pruned": boolean,
  "template_version": null
}
```

### Test Trace Format
Test traces use custom metadata formats:
```json
{
  "test_id": "string",
  "timestamp": "ISO8601 timestamp",
  "command": "cargo test/check",
  "workspace": "/path",
  "exit_code": integer
}
```
