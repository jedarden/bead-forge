### Issue to Fix
When `bf labels <id>` is called on a bead with no labels, it prints nothing. It should display a message like "No labels" to match the behavior of other commands (e.g., `bf comments list` shows "No comments for {id}").

### Root Cause
In `src/cli/mod.rs`, function `cmd_labels()` around line 2959-2961:
```rust
for label in &labels {
    println!("{}", label);
}
```
When `labels` is empty, the loop doesn't execute, resulting in no output.

### Recommended Fix
Add a check for empty labels array and print appropriate message:
```rust
if labels.is_empty() {
    println!("No labels");
} else {
    for label in &labels {
        println!("{}", label);
    }
}
```
