# Test Results: P0 Epic with Labels via CLI

## Date: 2026-08-06

## Tests Performed

### 1. List P0 Epics
```bash
bf list --priority 0 --type epic
```
✅ SUCCESS - Lists all P0 priority epics

### 2. Show Epic Details with Labels
```bash
bf show bf-29pk10
```
✅ SUCCESS - Displays epic with labels: critical, test-epic, umbrella

### 3. Create P0 Epic with Multiple Labels
```bash
bf create --type epic --priority 0 --title "CLI Test Epic P0 with Labels" \
  --description "Testing epic creation with P0 and labels" \
  --label test-label --label cli-test --label p0-verify
```
✅ SUCCESS - Created bf-5kobwc with all 3 labels

### 4. Add Labels to Existing Epic
```bash
bf label add bf-5kobwc --label updated-label --label another-label
```
✅ SUCCESS - Added 2 additional labels (now 5 total)

### 5. List Labels for Specific Epic
```bash
bf label list bf-5kobwc
```
✅ SUCCESS - Shows all labels: another-label, cli-test, p0-verify, test-label, updated-label

### 6. List All Unique Labels Across Workspace
```bash
bf label list
```
✅ SUCCESS - Shows 104 unique labels with usage counts

### 7. Remove Label from Epic
```bash
bf label remove bf-5kobwc --label updated-label
```
✅ SUCCESS - Removed label, epic now has 4 labels

### 8. JSON Output with Labels
```bash
bf show bf-5kobwc --format json
```
✅ SUCCESS - Returns JSON with labels array:
```json
{
  "id": "bf-5kobwc",
  "title": "CLI Test Epic P0 with Labels",
  "priority": 0,
  "issue_type": "epic",
  "labels": ["another-label", "cli-test", "p0-verify", "test-label"],
  ...
}
```

### 9. List P0 Epics in JSON Format
```bash
bf list --priority 0 --type epic --format json
```
✅ SUCCESS - Returns array of P0 epics with labels in JSON

## Key Findings

1. **Label Syntax**: Use `--label <value>` (singular), not `--labels` (plural)
2. **Multiple Labels**: Can specify `--label` multiple times for creation
3. **Label Management**: Separate `bf label` subcommands for add/remove/list
4. **JSON Support**: Labels are returned as arrays in JSON format
5. **Priority Values**: Use `0` for P0, not `P0` string
6. **Type Values**: Use `epic` (lowercase) for epic type

## All Operations Verified

- ✅ Create P0 epic with labels
- ✅ Add labels to existing epic  
- ✅ Remove labels from epic
- ✅ List labels for specific epic
- ✅ List all unique labels with counts
- ✅ Show epic details with labels
- ✅ JSON output includes labels array
- ✅ Filter by priority and type

## Conclusion

The bead-forge CLI fully supports P0 epic operations with labels through:
- `bf create` with `--label` flags
- `bf label add/remove/list` subcommands
- `bf show` and `bf list` with `--format json`
- Consistent label handling across all commands
