## Implementation Details

The JSON test infrastructure is organized into several modules:

1. **`json_validation`** - Core JSON parsing and field access
2. **`format_detection`** - Format type detection and validation
3. **`envelope`** - Envelope wrapping validation (version/kind/data)
4. **`fixtures`** - Test fixture creation (beads, labels, dependencies)
5. **`capture`** - Command output capture utilities

All modules are re-exported from `src/cli/tests/mod.rs` for convenient use:
```rust
pub use json_output::{
    test_workspace, bf_binary, bf_command, json_validation,
    format_detection, fixtures, envelope, capture,
};
```
