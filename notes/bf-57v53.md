## Root Cause Analysis

This is **NOT a regression** - it's an existing bug introduced when envelope format was added.

### Timeline

1. **2026-07-22 (02374fa)**: `autoflush_failure_contract.rs` was added to test that flush failures surface warnings in JSON output
2. **Later**: Envelope wrapping was implemented, changing JSON output from `{"id": "..."}` to `{"version": 1, "kind": "...", "data": {...}}`
3. **2026-07-23 (9d0c061)**: `claim_fallback` test was fixed to handle envelope-wrapped JSON
4. **Current**: `autoflush_failure_contract.rs` was **NOT updated** like `claim_fallback.rs`

### Two Issues

#### 1. Test not updated for envelope format
The test expects:
```rust
parsed.get("id").and_then(|v| v.as_str())
```

But envelope format has:
```json
{"version":1,"kind":"create","data":{"id":"bf-4j3"}}
```

The fix (from claim_fallback.rs):
```rust
let data = if json.get("version").is_some() && json.get("data").is_some() {
    &json["data"]
} else {
    &json
};
let id = data.get("id")...
```

#### 2. Warning not passed to envelope formatter
In `src/cli/mod.rs:1531-1537`:
```rust
let warning = autoflush_after_mutation(beads_dir, &config, no_auto_flush);

if json {
    let formatter = get_formatter(OutputFormat::Json);
    let data = serde_json::json!({ "id": id });
    let json_str = serde_json::to_string(&data)?;
    println!("{}", formatter.format_with_envelope("create", &json_str));  // BUG: should use format_with_envelope_and_warning
}
```

The `warning` is captured but not passed. Should be:
```rust
println!("{}", formatter.format_with_envelope_and_warning("create", &json_str, warning.as_deref()));
```

## Expected JSON Output (when fixed)

When auto-flush fails, the envelope should include the warning:
```json
{
  "version": 1,
  "kind": "create",
  "data": {"id": "bf-4j3"},
  "warning": "auto-flush to JSONL failed: Is a directory (os error 21); run \"bf sync --flush-only\" to retry"
}
```
