## Trace Capture Infrastructure

### Trace File System
- **Location**: `.beads/traces/`
- **Current State**: 368 trace directories present
- **Naming Convention**: `bf-{8-char-random}`
- **Structure**: Each trace contains:
  - `metadata.json` - Execution metadata and timing
  - `stdout.txt` - Standard output capture
  - `stderr.txt` - Standard error capture

### Trace Metadata Schema
```rust
pub struct TraceMetadata {
    pub bead_id: Option<String>,
    pub agent: String,
    pub provider: Option<String>,
    pub model: Option<String>,
    pub exit_code: Option<i32>,
    pub outcome: String,
    pub start_time: Option<String>,    // RFC3339 format
    pub end_time: Option<String>,      // RFC3339 format
    pub duration_ms: Option<u64>,       // Milliseconds
    pub input_tokens: Option<u64>,
    pub output_tokens: Option<u64>,
    pub cost_usd: Option<f64>,
    pub captured_at: String,
    pub trace_format: String,
    pub pruned: bool,
    pub template_version: Option<String>,
}
```

### TraceManager API
- **Creation**: `TraceManager::for_current_workspace()`
- **Test Execution**: `run_cargo_test_to_bead_trace_with_args()`
- **Features**:
  - Automatic trace directory creation
  - Output capture (stdout/stderr)
  - Timing information (start/end/duration)
  - Collision-resistant naming using SHA-256 + base36
