# BF-63wi63: Test Output Capture Implementation

## Summary
Implemented and verified test output capture mechanism for cargo test in bead-forge.

## Implementation Details

### Script Location
`scripts/capture-test-output.sh` - Bash script for capturing cargo test output

### Features
1. **Separate stdout/stderr capture**: Output streams are captured to separate files
2. **Metadata tracking**: JSON metadata file with test execution details
3. **Timing information**: High-precision duration tracking (nanosecond precision, millisecond output)
4. **Trace directory structure**: `.beads/traces/{bead_id}/`
5. **Exit code handling**: Preserves test exit code for CI/CD integration

### Output Format

#### Directory Structure
```
.beads/traces/{bead_id}/
├── metadata.json   # Test execution metadata
├── stdout.txt      # Standard output from cargo test
└── stderr.txt      # Standard error (compiler warnings, etc.)
```

#### Metadata JSON Format
```json
{
  "bead_id": "bf-63wi63-test",
  "test_name": "basic_test",
  "exit_code": 0,
  "outcome": "success",
  "duration_ms": 2846,
  "captured_at": "2026-07-24T13:03:38.242665667Z",
  "trace_format": "test_output",
  "test_command": "cargo test --lib -- -q",
  "stdout_bytes": 6774,
  "stderr_bytes": 10335
}
```

### Usage Examples

#### Basic Usage
```bash
# Run with default test command (cargo test -- -q)
bash scripts/capture-test-output.sh bf-63wi63

# Run with custom test name and command
bash scripts/capture-test-output.sh bf-63wi63 "unit_tests" cargo test --lib -- -q
```

#### Integration with CI/CD
```bash
# In CI pipelines
bash scripts/capture-test-output.sh "bf-${BEAD_ID}" "ci_test" cargo test --all
```
