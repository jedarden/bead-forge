# bf-1d22i6: Write Captured Output to Log Files

## Summary
Implemented atomic file writing functionality for captured stdout/stderr output with comprehensive unit tests.

## Changes Made

### 1. New Functions in `src/trace.rs`

#### `write_captured_output()`
- Writes both stdout and stderr to a single log file atomically
- Uses `std::fs::write()` for atomic file creation
- Creates parent directories if missing
- Returns `Result<(), io::Error>` as specified in acceptance criteria
- Format: `=== STDOUT ===\n{stdout}\n=== STDERR ===\n{stderr}`

#### `write_bead_output()`
- Convenience function that combines bead directory creation with output writing
- Integrates with trace directory structure from bf-5bb8tg
- Creates `.beads/traces/{bead_id}/output.log`
- Returns `Result<(), io::Error>`

### 2. Unit Tests Added (12 new tests)
All tests pass and verify the following requirements:

1. `test_write_captured_output_creates_file` - Basic file creation
2. `test_write_captured_output_atomic` - Verifies atomic write behavior
3. `test_write_captured_output_creates_parent_directories` - Directory creation
4. `test_write_captured_output_empty_content` - Empty content handling
5. `test_write_captured_output_large_content` - Large content (10k+ lines)
6. `test_write_captured_output_with_special_characters` - Special chars and unicode
7. `test_write_captured_output_overwrites_existing` - Overwrite behavior
8. `test_write_bead_output` - Bead-specific output writing
9. `test_write_bead_output_multiple_beads` - Multiple beads isolation
10. `test_write_bead_output_return_type` - Type signature verification
11. `test_write_captured_output_return_type` - Type signature verification
12. `test_write_captured_output_with_newlines` - Newline preservation
13. `test_write_captured_output_idempotent` - Repeated write behavior

### 3. Integration with Existing Trace Directory Structure
- Uses existing `bead_trace_dir()` from bf-5bb8tg
- Follows `.beads/traces/{bead_id}/` directory convention
- Outputs to `output.log` within bead trace directories

## Design Decisions

### Return Type: `Result<(), io::Error>`
- Used `std::io::Error` instead of `anyhow::Result` as specified in acceptance criteria
- Provides direct error type for file operations
- Allows caller to distinguish between IO errors and other errors

### Atomic Writing with `std::fs::write()`
- Uses Rust's standard library for atomic file creation
- On success, file is completely written or not at all
- Prevents partial writes and corrupted output files

### Parent Directory Creation
- Automatically creates parent directories with `fs::create_dir_all()`
- Provides descriptive error messages if directory creation fails
- Idempotent - safe to call multiple times

### Output Format
- Sections are clearly delimited with `=== STDOUT ===` and `=== STDERR ===`
- Preserves exact content including newlines and special characters
- Single file format simplifies log file management
