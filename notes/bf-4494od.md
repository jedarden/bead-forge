## Trace Naming Convention Details

### Directory Format
- Basic: `.beads/traces/{bead_id}/`
- Unique runs: `.beads/traces/{bead_id}-{timestamp}/`
- With counter: `.beads/traces/{bead_id}-{timestamp}-{counter}/`

### Example Paths
- `bf-4494od-20260724-184148-376/` - Unique run with milliseconds
- `bf-4494od-20260724-184148-376-01/` - With counter if needed

### Files in Each Trace Directory
- `metadata.json` - Execution metadata (bead_id, agent, timing, etc.)
- `stdout.txt` - Standard output capture
- `stderr.txt` - Standard error capture
