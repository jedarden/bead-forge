# Bead bf-269i1l: Epic Explicit P2

## Summary

Verification bead in the harness-test series. Confirms that a bead created with
`--type epic` and an **explicit** `--priority 2` correctly stores priority
**2 (P2 / Normal)**. This is the *explicit-flag* complement to the default-P2
siblings (`bf-1itsrb`, `bf-2xc4za`): it exercises the path where the user passes
`--priority 2` on the command line rather than relying on the clap default.
No code changes were required; this note is the commit artifact.

## Source of the behavior

`src/cli/mod.rs` — the `create` command declares `--priority` with a clap
`default_value` of `"2"`, parsed independently of `--type`:

```rust
// src/cli/mod.rs:61-67
/// Bead type
#[arg(long, default_value = "task")]
type_: String,

/// Priority (0=Critical, 4=Backlog)
#[arg(long, default_value = "2")]
priority: i32,
```

`priority` is then forwarded verbatim into `cmd_create`
(`src/cli/mod.rs:1113-1131` — destructured out of the clap struct and passed as
the `priority` argument). There is no branching on the flag's provenance: a
value that came from an explicit `--priority 2` and a value that came from the
clap default are the **same `i32`** by the time `cmd_create` sees them. So an
explicit `--priority 2` cannot diverge from the default — both resolve to `2`.

## Empirical verification

Created a throwaway epic with an explicit `--priority 2`, inspected it, then
deleted it so `.beads/issues.jsonl` was not polluted by a test bead:

```
$ br create --title "TEMP explicit-priority probe (bf-269i1l)" --type epic --priority 2
bf-4tmy0j

$ br show bf-4tmy0j --json
[{"id":"bf-4tmy0j","title":"TEMP explicit-priority probe (bf-269i1l)",
  "description":"","design":"","acceptance_criteria":"","notes":"",
  "status":"open","priority":2,"issue_type":"epic", ...}]

$ br delete bf-4tmy0j
Deleted bead bf-4tmy0j

$ grep -c bf-4tmy0j .beads/issues.jsonl
0
```

- Probe epic `bf-4tmy0j` received `priority=2` (P2) from the explicit
  `--priority 2` flag. ✓
- `issue_type` was correctly `epic`. ✓
- Probe was deleted; `grep -c bf-4tmy0j .beads/issues.jsonl` → `0` (clean). ✓
