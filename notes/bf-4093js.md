## Related Implementation

The test relies on the assignee clearing logic in `update_issue()` (lines 598-606):

```rust
if let Some(ref assignee) = changes.assignee {
    if assignee.trim().is_empty() {
        // Clearing stores NULL, never an empty string that would
        // read back as "assigned" and hide the bead from claiming.
        updates.push("assignee = NULL");
    } else {
        updates.push("assignee = ?");
        params.push(Box::new(assignee.clone()));
    }
}
```

This ensures that when an empty string is passed, the database field is set to NULL, not an empty string.
