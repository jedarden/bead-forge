## Key Finding
The `--envelope` flag is not wrapping JSON output for several commands (claim, batch, ready, recent, search, velocity). These commands should return:
```json
{
  "version": 1,
  "kind": "<command>",
  "data": <result>
}
```
But are returning raw JSON without the envelope wrapper.
