# Bead bf-1ik417: Verify Epic Label Addition and Removal

## Summary
Verified that label addition and removal functionality works correctly for epic beads.

## Tests Performed

### 1. Create Epic with Initial Label
```bash
bf create --title "Test epic for label verification" --type epic --label test-label
# Created bf-6bnjea
```

### 2. Verify Initial Label
```bash
bf labels bf-6bnjea
# Output: test-label
```

### 3. Add New Label
```bash
bf label add bf-6bnjea --label new-label
# Output: Added label 'new-label' to bf-6bnjea
```

### 4. Verify Label Addition
```bash
bf labels bf-6bnjea
# Output:
# new-label
# test-label
```

### 5. Remove Label
```bash
bf label remove bf-6bnjea --label new-label
# Output: Removed label 'new-label' from bf-6bnjea
```

### 6. Verify Label Removal
```bash
bf labels bf-6bnjea
# Output: test-label
```

### 7. Roundtrip Test - Add Multiple Labels
```bash
bf label add bf-6bnjea --label roundtrip-test
bf label add bf-6bnjea --label another-label
bf labels bf-6bnjea
# Output:
# another-label
# roundtrip-test
# test-label
```

### 8. Roundtrip Test - Remove One Label, Verify Others Preserved
```bash
bf label remove bf-6bnjea --label roundtrip-test
bf labels bf-6bnjea
# Output:
# another-label
# test-label
```

## Result
✅ All acceptance criteria met:
- Add label to existing epic works correctly
- Label addition verified with `bf labels <bead-id>`
- Remove label from epic works correctly  
- Label removal verified with `bf labels <bead-id>`
- Add/remove roundtrip preserves other labels
