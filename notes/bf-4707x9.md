## Implementation Note

The bead-forge implementation returns an empty string `""` when commands produce no results (e.g., listing closed beads when none exist, or searching with a term that matches nothing). This is valid behavior as long as JSON consumers handle both empty strings and empty arrays correctly.

The dedicated empty result test file (`test_empty_result_json_output.rs`) was already designed to handle both behaviors, but the edge case consistency tests had stricter expectations that didn't match the actual implementation.
