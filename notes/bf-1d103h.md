# Security Patch: bf-1d103h

## Issue
P0 Security vulnerability in `src/lib.rs` line 55

## Vulnerability
The code was exposing internal implementation details at the crate root level:
```rust
pub use storage::{schema, sqlite, Storage};
```

This exposed:
1. **`schema` module** - Full database schema via `SCHEMA_SQL` constant
2. **`sqlite` module** - Internal storage backend implementation

## Security Impact
- External code could access `bead_forge::schema::SCHEMA_SQL` to view complete database structure
- Direct access to internal storage implementation bypassing the public `Storage` API
- Potential for data corruption if external code manipulates database directly
- Violation of encapsulation principles

## Fix
Reverted to exposing only the public API:
```rust
pub use storage::Storage;
```

## Verification
- ✅ Library compiles successfully
- ✅ Internal modules properly encapsulated
- ✅ Only public `Storage` interface exposed

## Files Changed
- `src/lib.rs` - Line 55: Removed `schema` and `sqlite` from public exports
