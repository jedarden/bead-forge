### 4. Error handling for directory creation failures ✅

**Implementation:** `TraceCapture::new_with_sanitizer()` in `/home/coding/NEEDLE/src/trace/mod.rs:126-152`

```rust
pub fn new_with_sanitizer(
    bead_id: &BeadId,
    beads_root: &Path,
    sanitizer: Option<Arc<Sanitizer>>,
) -> Option<Self> {
    let trace_dir = beads_root
        .join(".beads")
        .join("traces")
        .join(bead_id.as_ref());

    // Create the trace directory.
    if let Err(e) = std::fs::create_dir_all(&trace_dir) {
        tracing::warn!(
            bead_id = %bead_id,
            path = %trace_dir.display(),
            error = %e,
            "failed to create trace directory, trace capture disabled"
        );
        return None;
    }

    Some(TraceCapture {
        trace_dir,
        enabled: true,
        sanitizer,
    })
}
```

**Error Handling Characteristics:**
- Returns `None` on directory creation failure
- Logs structured warning with context (bead_id, path, error)
- Gracefully degrades (trace capture disabled rather than failing)
- Uses `create_dir_all` to create parent directories automatically
