## Pattern Analysis

### Root Cause
All failures stem from the `--envelope` flag not working correctly. The CLI is not wrapping JSON output in the expected envelope structure with:
- `version: 1`
- `kind: <command_name>`
- `data: <command_result>`

### Commands Affected
1. **claim** - 6 failures (version field missing, structure issues)
2. **batch** - 2 failures (data not an array)
3. **ready** - 1 failure (data not an array)
4. **recent** - 2 failures (data not an array)
5. **search** - 2 failures (no JSON output, version field missing)
6. **velocity** - 1 failure (data structure incorrect)

### Commands Working Correctly
- create (envelope structure ok)
- list (envelope structure ok)
- show (envelope structure ok)
- stats (envelope structure ok)
